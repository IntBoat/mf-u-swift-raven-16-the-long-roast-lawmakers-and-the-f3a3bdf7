# The Long Roast: Lawmakers and the File They Cannot Convert

A one-sentence entry for the make.fun competition "The Long Roast: Lawmakers and the File They Cannot Convert": one satirical sentence, at most 320 characters, roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF.

The program in `main.py` writes the entry text to `/output/entry.txt`, where the competition's sealed scorer reads it.

Competition: https://make.fun/api/competitions/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7/requirements

## Entry
